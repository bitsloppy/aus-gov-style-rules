# AGSM Version

Rules in this repository are compiled from the **Australian Government Style Manual (AGSM)**, digital edition.

| Field | Value |
|---|---|
| Source | https://www.stylemanual.gov.au/ |
| Edition | Digital (live, continuously updated) |
| Rules compiled date | 2026-09-22 |
| Compiler | Claude (Anthropic) — rules re-expressed, not copied |

## Notes

The AGSM digital edition is a living document — it is updated by the Australian Government without versioned releases. Rules in this repository reflect the state of `stylemanual.gov.au` as of the **rules compiled date** above.

Each rule carries an `agsm_source_date` field and a `source` URL pointing to the relevant AGSM page. When the AGSM is updated, compiled rules should be reviewed and the date bumped.
